# Спецификация: Сценарий «Задачи из чек-листа»

## Интент
Пользователь спрашивает про задачи на период (1 неделя, 1 месяц, 3 месяц).

## Вход
- Текст пользователя: «Какие у меня задачи на неделю?»
- Роль пользователя: `intern_backend` / `intern_frontend` / `mentor`

## Логика
1. Бот распознаёт интент «задачи» через LLM (промпт ReAct).
2. LLM возвращает команду `[GET_TASKS: <период>]`.
3. Бэкенд идёт в PostgreSQL, фильтрует задачи по `period` и `role`.
4. **RBAC:** пункты, начинающиеся с «Добавь», «Проверь», «Назначь» — показываются только наставнику.
5. LLM красиво оформляет список (второй запрос).

## Выход
Список задач с заголовком и описанием.

## Ошибки
- Нет задач на период → «Задач на этот период не найдено».
- LLM недоступна → фолбэк на сырой текст из базы.
