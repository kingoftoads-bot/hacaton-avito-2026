# Спецификация: Сценарий «Отгул»

## Интент
Пользователь просит отгул / отпуск.

## Вход
- Текст: «Хочу отгул на завтра»

## Логика
1. Бэкенд распознаёт ключевые слова «отгул», «отпуск».
2. Вызывает Mock API: `POST /absence/request`.
3. Mock API возвращает номер заявки (например, `ABS-7545`).
4. Бот показывает инструкцию + номер + статус + следующие шаги.

## Выход
- Номер заявки
- Статус: «На согласовании у руководителя»
- Следующий шаг: «Если нет ответа через 2 дня — напиши руководителю»

## Ограничения
- Реальная система отсутствий Авито не подключена (имитация).
- Финансовые операции не затрагиваются.
