# Спецификация: Сценарий «Доступы»
## Интент
Пользователь просит доступ к Jira / Confluence / другому ресурсу.

## Вход
- Текст: «Как получить доступ к Jira?»

## Логика
1. Бэкенд распознаёт интент «доступ».
2. Вызывает Mock API: `POST /access/request` с параметрами:
   - resource: `jira`
   - level: `read`
   - reason: «Для работы над задачами»
3. Mock API возвращает номер заявки (`ACC-7550`).
4. Бот показывает номер + статус + кто согласует.

## Выход
- Номер заявки
- Ресурс + уровень прав
- Статус: «Направлена владельцу проекта»

## RBAC
- Стажёр может запрашивать только `read`.
- `edit` и `admin` — только через наставника (`/approve`).
