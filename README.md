# AI-buddy — ИИ-наставник для стажёров Авито

Прототип ИИ-ассистента для адаптации стажёров. Бот подсказывает задачи по чек-листу, объясняет процедуры (отгул, доступы) и выполняет действия через имитации корпоративных сервисов.

## Требования

- Docker и Docker Compose
- [Ollama](https://ollama.com) — локальный запуск LLM (ключ API не нужен)

1. Установите Ollama и скачайте модель:
2. Скопируйте `.env.example` в `.env`:
3. Запустите:
4. Откройте:
- Frontend: http://localhost:3000
- Backend API: http://localhost:8080

## Тестовые пользователи

- `intern_backend` — стажёр Backend
- `intern_frontend` — стажёр Frontend
- `mentor` — наставник

## Технологии

- Backend: Go
- Frontend: React + TypeScript
- БД: PostgreSQL
- LLM: Ollama (`gemma3:4b-it-qat`) — локально, без внешних ключей

## Проверка сценариев

1. «Какие у меня задачи на 1 неделю?» — бот вернёт пункты чек-листа.
2. «Хочу отгул» — бот даст инструкцию и создаст заявку (Mock API).
3. «Как получить доступ к Jira?» — бот покажет форму заявки (Mock API).

## Ограничения прототипа

- Корпоративные сервисы — имитации (Mock API).
- Только синтетические данные, без реальных ПДн.
- SSO и внутренние инструменты Авито (MCP, feature flags) — описаны в презентации как путь в прод.
