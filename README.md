# AI-buddy — ИИ-наставник для стажёров Авито

**Хакатон Hack&Change 2026** | Команда: **Лень И Успех**

> Прототип: AI-buddy — ИИ-наставник для адаптации стажёров.

---

## 📋 О проекте

AI-buddy помогает стажёрам быстрее адаптироваться в команде: подсказывает задачи из корпоративного чек-листа, объясняет процедуры (отгулы, доступы) и выполняет действия через имитацию корпоративных сервисов (Mock API).

**Ценность:**
- **Для стажёра:** единая точка входа для ответов на рабочие вопросы.
- **Для наставника:** сокращение рутинных объяснений.

## 🚀 Быстрый запуск (Локальный)

### 1. Подготовка окружения

Убедитесь, что у вас установлены:

- **Go** (версия 1.22+)
- **Node.js** (версия 20+)
- **PostgreSQL** (создайте базу данных `aibuddy` с паролем `root` для пользователя `postgres`)
- **Ollama** ([скачать](https://ollama.com))

### 2. Запуск LLM (Ollama)

В отдельном терминале выполните:

```bash
ollama pull gemma3:4b-it-qat
ollama serve
```

> Модель скачается автоматически (~2 ГБ).

### 3. Запуск Backend (Go)

В отдельном терминале выполните:

```bash
cd backend
go mod tidy
go run .
```

> Бэкенд сам подключится к PostgreSQL, создаст таблицу `tasks` и загрузит в неё данные из `checklist.xlsx`.

### 4. Запуск Frontend (React)

В отдельном терминале выполните:

```bash
cd frontend
npm install
npm run dev
```

### 5. Открыть в браузере

Перейдите по адресу: **http://localhost:5173**

## 🎯 Реализованные сценарии (MVP)

- **📋 Задачи из чек-листа** — Бот распознаёт интент, достаёт задачи из PostgreSQL и красиво оформляет их с учётом роли. Задачи динамически обновляются при отметке.
- **📅 Оформление отгула** — Бот объясняет процедуру и вызывает Mock API (`POST /absence/request`), возвращая номер заявки.
- **🔐 Запрос доступов** — Бот создаёт заявку на доступ к Jira/Confluence через Mock API (`POST /access/request`), возвращая номер и статус.

---

## 🏗 Архитектура и безопасность

- **RBAC (Ролевая модель):** Задачи фильтруются на уровне SQL-запроса (пункты наставника не показываются стажёру).
- **Имитация корпоративных сервисов:** Mock API реализованы прямо в бэкенде.
- **Безопасность:** Используются только синтетические данные. Персональные данные не передаются в LLM.
- **SDD-спецификации:** Описание поведения агента находится в папке `/specs`.

---

## 📈 Метрики пользы (как проверить эффект)

- **Self-service rate:** % вопросов, закрытых ботом без эскалации к наставнику (цель: >60%).
- **Скорость онбординга:** Время до первого самостоятельного коммита (baseline vs с ботом).
- **CSAT стажёра:** Оценка полезности бота после каждого ответа (цель: >4.5/5).

## 🐳 Запуск через Docker (Опционально)

Мы подготовили `docker-compose.yml`. Однако, так как используется локальная Ollama, для запуска через Docker требуется, чтобы Ollama была запущена на хост-машине (в Windows/Mac это работает через `host.docker.internal`).

> **Рекомендуемый способ запуска — локальный** (см. выше), так как он гарантированно работает без настройки сетей.
